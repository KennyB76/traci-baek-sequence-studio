Arithmetic & Geometric Sequences: 20 Simple Questions

Traci BaekSeptember 30, 2026
HSF-BF.A.2 — Arithmetic and geometric sequences: explicit and recursive rules.

20 short questions. Use integer term numbers. Show one useful step for each answer.

1. For \(2,5,8,11,\ldots\), find the common difference and the next term.
2. Find the common difference of \(1,5,9,13,\ldots\).
3. For \(11,8,5,2,\ldots\), find the common difference and the next term.
4. If \(a(n)=4n-3\), find \(a(3)\). Write the same answer using subscript notation.
5. Write an explicit rule for \(2,5,8,11,\ldots\), starting at \(a_1=2\).
6. An arithmetic sequence has \(a_1=4\) and \(d=5\). Write an explicit rule.
7. For \(1,5,9,13,\ldots\), find \(a_5\) and \(a_{100}\).
8. For \(2,5,8,11,\ldots\), give the starting term and a recursive rule. Use either previous-term or next-term notation.
9. Given \(a_1=7\) and \(a_{n+1}=a_n+2\), list the first four terms.
10. An arithmetic sequence starts at \(a_0=5\), with common difference 3. Write an explicit rule.
11. For \(3,6,12,24,\ldots\), find the common ratio and the next term.
12. For \(16,8,4,2,\ldots\), find the common ratio and the next term.
13. For \(2,-6,18,-54,\ldots\), find the common ratio and the next term.
14. A geometric sequence has \(a_1=2\) and \(r=3\). List the first four terms.
15. Write an explicit rule for \(3,6,12,24,\ldots\), starting at \(a_1=3\).
16. A geometric sequence has \(a_1=5\) and \(r=2\). Find \(a_5\).
17. For \(1,\tfrac13,\tfrac19,\ldots\), find the common ratio and \(a_4\).
18. For \(3,6,12,24,\ldots\), give the starting term and a recursive rule.
19. Given \(p(0)=-2\) and \(p(n)=5p(n-1)\) for integers \(n\ge1\), list \(p(0),p(1),p(2)\) and write an explicit rule.
20. Classify each sequence and give its common difference or ratio: A: \(2,4,6,8,\ldots\); B: \(2,4,8,16,\ldots\).
